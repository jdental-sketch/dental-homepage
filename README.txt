정치과의원 홈페이지 - 페이지 분리 버전

파일 구성
- index.html: 메인 페이지
- treatment.html: 진료안내
- tour.html: 치과둘러보기
- notice.html: 공지사항
- location.html: 오시는길
- css/style.css: 모든 페이지 공통 디자인
- CNAME: 기존 도메인 설정 파일

GitHub 반영 방법
1. 압축을 푼 뒤 파일과 css 폴더를 저장소의 루트에 올립니다.
2. 기존 index.html을 포함해 파일을 교체하고 변경 사항을 Commit합니다.
3. GitHub Pages 배포가 끝나면 사이트 메뉴에서 각 페이지로 이동하는지 확인합니다.

참고
- 홈페이지의 기존 주소, 전화번호, 진료시간 문구는 원본에서 가져왔습니다. 실제 정보와 일치하는지 배포 전 확인해 주세요.
- 치과둘러보기의 사진은 아직 자리표시자입니다.
- 공지사항은 정적 HTML 목록입니다. 직접 목록을 수정해야 새 공지가 올라갑니다.
